# Studio App — 콘텐츠 스튜디오

정부사업 제안서·평가보고서처럼 **정해진 형식(서식)에 맞춰야 하는 문서**를
빠르고 정확하게 작성할 수 있도록 돕는 콘텐츠 제작 웹앱입니다.

## 무엇을 위한 앱인가요

- 디자인 작업에는 익숙하지만 문서의 **논리 구조(기승전결, 목차 순서)** 를
  매번 새로 고민하는 것이 부담스러운 분들을 위해, 문서 종류별로 검증된
  **섹션 구조와 작성 가이드**를 미리 제공합니다.
- 각 섹션마다 "무엇을, 어떤 순서로 써야 하는지" 안내 문구가 함께 표시되어
  내용만 채우면 형식이 자동으로 맞춰집니다.
- 완성한 문서는 **.docx(Word)** 파일로 내보낼 수 있습니다. 한글(HWP)은
  .docx 파일을 바로 불러오기 할 수 있어, 이후 한글 프로그램에서 마무리
  편집하기 편리합니다.

## 시작하기

```bash
cd studio-app
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 주요 기능

1. **템플릿 선택** — 제안서 / 평가보고서 중 문서 종류를 고릅니다.
2. **구조화된 에디터** — 섹션별 제목, 작성 가이드, 입력창이 순서대로
   제공됩니다. 목차·순서를 고민할 필요 없이 내용만 채우면 됩니다.
3. **자동 저장** — 브라우저(localStorage)에 자동으로 저장되어 이어서
   작업할 수 있습니다.
4. **DOCX 내보내기** — 표지, 목차, 섹션 제목/본문이 서식에 맞춰 정리된
   Word 파일로 한 번에 내보냅니다.

## 기술 스택

- Next.js (App Router) + TypeScript
- [`docx`](https://www.npmjs.com/package/docx) 라이브러리로 브라우저에서
  바로 .docx 파일 생성
- 별도 서버/DB 없이 localStorage 기반으로 동작 (추후 서버 저장소로 확장 가능)
